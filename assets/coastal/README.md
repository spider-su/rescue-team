# Original coastal artwork

Created for Rescue Team on 2026-10-31 with Codex's built-in image generation tool. All visual references were original UI concepts generated in this conversation, not third-party game screenshots or extracted assets. The selected outputs are copied into this repository and used directly by `scripts/coastal_style.gd` and `scripts/board_view.gd`.

| File | Use |
| --- | --- |
| `harbor.png` | Mission selection illustration and cropped card thumbnails |
| `victory.png` | Completed-rescue illustration |
| `crew-atlas.png` | Transparent firefighter, engineer and civilian portraits/sprites |
| `props-atlas.png` | Transparent crate, fire, switch, closed/open gate and exit arrow |
| `board-backdrop.png` | Decorative harbor surroundings behind the opaque puzzle grid |

Atlas regions are selected with Godot `AtlasTexture`; original raster files are preserved. Regions match the inspected output, rather than assuming a perfect generated grid. Decorations do not supply collision or pathfinding data. The original SVG assets remain in the project as earlier artwork, but the coastal renderer uses these atlases.

Typography: Barlow Regular and Barlow Condensed SemiBold from the [Google Fonts Barlow](https://github.com/google/fonts/tree/main/ofl/barlow) and [Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed) directories. Corresponding SIL Open Font License notices are included under `assets/fonts/`. UI command SVGs are original source drawings in this repository.

## Generation prompts

Built-in tool mode was used for all five assets; no API/CLI fallback or third-party asset extraction was used. The UI concept was the style reference for the first four prompts; the resulting `harbor.png` was the reference for the backdrop.

### Harbor

Depict ONLY the coastal harbor illustration from the LEFT screen, expanded edge to edge with NO UI, lettering, frames, cards or overlays. Warm illustrated European coastal town, terracotta roofs, cream stone workshops, turquoise water and boats, a lighthouse in the distance. Foreground at lower left: the same friendly adult female firefighter with brown ponytail, yellow helmet, orange uniform and water backpack, beside the same adult bearded male engineer with blue hardhat, goggles, navy work clothes and tool harness. They look toward the town with capable hopeful expressions. Hand-painted polished 2D game art, clear elegant shapes, soft sun, restrained texture, match reference palette and original characters. Hero scene for an Android mission selection screen. Keep heads away from image borders. No children, no text, no gameplay grid, no phone mockup. The entire output is the illustration.
